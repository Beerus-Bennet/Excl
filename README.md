# Excel.net (PWA)

Eine moderne, browserbasierte Tabellenkalkulations-Anwendung als Progressive Web App (PWA).

## 🚀 Features

- **Excel-Kompatibilität:** Erstellen, Bearbeiten und Anzeigen von Tabellenkalkulationen.
- **PWA-Unterstützung:** Kann auf iOS (Safari) und Android (Chrome) als Standalone-App zum Home-Bildschirm hinzugefügt werden.
- **Mobile-Optimiert:** Anpassung an Smartphone-Displays inkl. Safe-Area für iPhones.
- **Import & Export:** Öffnen und Speichern von Datei-Formaten.
- **iOS Share Sheet Integration:** Nutzen der nativen Teilen-Funktion zum Speichern auf mobilen Endgeräten.

## 🛠️ Technologien

- **Luckysheet** (Tabellenkalkulations-Engine)
- **Luckyexcel** (Import & Export)
- **HTML5, CSS3, JavaScript** (Vanilla Web Stack)

## 📱 Installation (iOS)

1. Öffne die GitHub-Pages-URL in **Safari**.
2. Tippe auf das **Teilen-Symbol** (Quadrat mit Pfeil nach oben).
3. Wähle **"Zum Home-Bildschirm"**.
